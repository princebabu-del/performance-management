# Number stepper

Number input with increase / decrease buttons stacked inside its right edge (peer reviewer count, due-date days, weightage %).

| File | What it is |
| --- | --- |
| `NumberStepper.tsx` | **The spec.** Anatomy, sizes, field + button states, press-and-hold, keyboard, tokens, a typed `NumberStepper` and a `NumberStepperStates` gallery |

Prototype markup today: `.number-stepper` > `input.input.input--number` + `.number-stepper__buttons` (src/styles/16-reviewers-setup.css).
