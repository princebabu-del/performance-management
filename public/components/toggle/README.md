# Toggle

On / off switch for settings that apply immediately, with a label (before or after, optional description) or on its own with an `aria-label`.

| File | What it is |
| --- | --- |
| `Toggle.tsx` | **The spec.** When to use (vs checkbox), anatomy with and without label, sizes (36×20, 44×24), states, accessibility, tokens, a typed `Toggle` and a `ToggleStates` gallery |

No shared toggle CSS exists in the prototype yet; new screens should use the `.toggle` class names from the spec.
